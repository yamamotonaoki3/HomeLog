# アイコン組み込み計画（#384）

**Goal:** 選定済みA案「青地に白い家＋記録」をファビコン・iOS・PWAへ組み込む。
**Architecture:** 承認済みPNGを縮小し、ファビコン・ホーム画面用画像としてpublicから配信する。既存SVG参照との互換性を保ち、SVG内には同じ画像の縮小版を埋め込む。PWAの通常用とmaskable用を明示する。
**Tech Stack:** Vite / vite-plugin-pwa / Playwright。新依存・API・DB変更なし。

## 対象
- `frontend/public/`：favicon.svg・favicon.ico、apple-touch-icon.png（180px）、pwa-192.png、pwa-512.png、maskable-512.png。
- `frontend/index.html`：faviconとapple-touch-iconの参照。
- `frontend/vite.config.ts`：PWA iconsと画像キャッシュ対象。
- `e2e/tests/static-assets.spec.ts`：実WorkersのHTML・manifest・画像配信契約。
- `docs/details/common-notes.md`：共通アイコン仕様。

## 検証記録
- frontend：全495テスト成功（47ファイル）、lint成功（既存警告あり）、build成功。
- 180/192/512px PNGは寸法通りで、全画素の透明度255を確認。ICOは16/32/48pxを格納。
- PWA生成物のService Workerに6種類のアイコン参照が含まれることを確認。
