# 技術スタック構成

[← 要件定義書に戻る](requirements.md)

本番は Cloudflare Workers 上で動く TypeScript 版（`backend-workers/` ＋ `frontend/`）である。当初の Java/Spring Boot 版（`backend/`）は移行元として残しているが、本番では使っていない（2026-10 時点）。バージョンは各 `package.json` を正とする。

## バックエンド（`backend-workers/`）

| 役割 | 技術 |
| --- | --- |
| 実行環境 | Cloudflare Workers（`nodejs_compat`） |
| 言語 | TypeScript 5.7 |
| Web フレームワーク | Hono 4 |
| データベース | Cloudflare D1（SQLite 互換） |
| DB アクセス | drizzle-orm 0.45（スキーマ定義）＋ D1 の prepared statement / batch |
| マイグレーション | `backend-workers/drizzle/*.sql` を `wrangler d1 migrations apply` で適用 |
| 入力検証 | zod 3 |
| 認証 | 自前 JWT（アクセストークン15分）＋ リフレッシュトークン（7日、DB 管理）。パスワードは Web Crypto の PBKDF2-SHA256（10万回） |
| ファイル保存 | Cloudflare R2（手書きレシピ画像の一時保存） |
| 手書きレシピの解析 | Google Cloud Vision（文字認識）＋ Workers AI（LLM でタイトル・材料・手順に整理） |
| 定期処理 | Cron Trigger（毎日 JST 1:00）：固定費の自動計上・OCR 画像の削除・退会アカウントの削除 |
| Lint | ESLint 9 ＋ typescript-eslint |
| テスト | Vitest 4 ＋ `@cloudflare/vitest-pool-workers`（miniflare 上の本物の D1 で実行） |

## フロントエンド（`frontend/`）

| 役割 | 技術 |
| --- | --- |
| ライブラリ | React 19 ＋ TypeScript 6 |
| ビルド | Vite 8 |
| ルーティング | react-router-dom 7 |
| HTTP 通信 | axios 1 |
| PWA | vite-plugin-pwa（Web Share Target でレシピ URL を受け取る） |
| Lint | oxlint 1 |
| テスト | Vitest 4 ＋ jsdom ＋ Testing Library ＋ msw 2 |

## E2E テスト（`e2e/`）

- Playwright 1.63。ローカルの Workers（8787）と Vite（5181）を起動し、PC・スマホ幅（1280 / 390 / 320px）で画面と API を通しで確認する。テストデータは `e2euser_` 接頭辞・`[E2E_TEST]` タグで識別し、実行後に削除する。

## インフラ・配信

| 項目 | 内容 |
| --- | --- |
| ホスティング | Cloudflare Workers（API）＋ Workers Static Assets（`frontend/dist` を同じ Worker から配信、SPA フォールバック） |
| デプロイ | Cloudflare Workers Builds。`production` ブランチへの push で、マイグレーション適用 → デプロイを自動実行（[deployment.md](deployment.md)） |
| CI | GitHub Actions（backend-quality / frontend-quality / e2e / gitleaks） |
| 秘密情報 | `wrangler secret`（本番）・`.dev.vars`（ローカル、コミットしない） |

## 運用方針

- 家族利用の段階では Cloudflare の無料枠の範囲で運用する。
- 利用規模が大きくなった場合は、D1 の容量・Workers の実行時間制限を踏まえて構成を見直す。
