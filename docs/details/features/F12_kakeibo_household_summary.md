<a id="使い方の概要"></a>

## 使い方

1. [支出](F03_kakeibo_expense.md)や[固定費](F05_kakeibo_fixedcost.md)を登録するときに「世帯合計に含める」を選びます。
2. ホームの「今月のお金」カードか、家計簿の当月集計で「世帯合計対象額」を確認します。

ホームで金額が見つからない場合は、表示設定でカードと項目を表示し、「今月のお金」カードを開きます。

[集計に含まれる金額](#集計に含まれる金額) ｜ [技術詳細](#技術詳細)

## 集計に含まれる金額

| 集計対象 | 条件 |
| --- | --- |
| 支出 | 世帯合計の対象にした、その世帯の当月（日本時間）の支出。 |
| 固定費 | 世帯合計の対象にした、その世帯の登録中の固定費。当月に計上される前も見込み額として含める。 |

世帯メンバーに共有するのは合計額です。個別の支出明細は、それぞれの登録者が閲覧できます。

## 1. 概要

世帯全体としてどれだけ支出があったかを、個人の支出内訳を非公開にしたまま合計金額のみで確認できるようにする機能（[common-notes.md](../common-notes.md) 8章参照）。世帯全体の合算家計簿（個別の支出管理）ではなく、あくまで集計値の閲覧に限定する。

トップ画面（S-04）の「今月のお金」カードと、家計簿一覧画面（S-05）の当月集計に表示する。S-04では表示設定（S-21）でカード全体または世帯合計対象額の項目を非表示にでき、カードを折りたたむと明細は隠れる。S-05では当月集計の固定項目として表示する（[共通事項](../common-notes.md) 9章参照）。

## 2. 対象画面

| 画面ID | 画面名 |

| S-04 | トップ画面（表示設定と開閉状態に応じて「今月のお金」カードに表示） |

## 3. 業務フロー

```mermaid
flowchart TD
    A([世帯の当月集計を取得]) --> B[対象フラグが有効な\n世帯の当月支出を集計]
    B --> C[対象フラグが有効な\n世帯の固定費を集計]
    C --> D[世帯合計対象額を返す]
    D --> E["S-04の「今月のお金」\n表示設定と開閉状態に従う"]
    D --> F["S-05の当月集計\n固定項目として表示"]
```

## 4. IPO

### 世帯合計支出の取得

| 項目 | 内容 |
| --- | --- |
| 入力 | household_id・対象期間（当月固定） |
| 処理 | `include_in_household_total=true` の世帯の当月支出（JST）と、登録中の世帯の固定費を合算する。固定費は当月の計上有無にかかわらず見込み額として扱う |
| 出力 | 世帯合計支出額（内訳は含まない） |
