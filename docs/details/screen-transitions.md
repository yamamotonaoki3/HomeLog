# 画面遷移図

[← 要件定義書に戻る](../requirements.md)

全画面のレイアウトは[wireframes.md](wireframes.md)を参照する。S-24イベント詳細モーダルを追加した。

「登録・編集は各機能画面、確認はトップ（S-04 生活ダッシュボード）に集約」という方針（[common-notes.md](common-notes.md) 9章）により、旧S-16（世帯合計支出画面）・旧S-20（イベント別支出サマリーモーダル）は独立画面として廃止し、S-04内のサマリーカードに統合した。S-04のイベント確認用としてS-24イベント詳細モーダルを新設する。

## 3. 在庫・イベントの直接編集（#332 / #333）

在庫の品目行は詳細編集モーダルを直接開く。個数は表示枠の外側の＋／－で即時反映し、他の項目は保存で確定する。イベントの登録者はS-18の編集モードを直接開き、支出集計・削除確認まで同じモーダルで操作する。他の登録者の共有イベントは一覧内の閲覧専用詳細を開く。トップ画面から開くS-24は引き続き閲覧専用で、編集への遷移は設けない。
