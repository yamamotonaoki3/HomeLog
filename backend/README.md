# 旧Java版の設定について

このディレクトリは移行元の保管用です。現在の本番APIと新規開発は `backend-workers/` を使います。

旧Java版をローカルで確認する場合に限り、次の環境変数を用意してください。実値はコミット・ログ出力せず、本番やWorkers版とは別のローカル専用値を使います。

| 環境変数 | 用途 |
| --- | --- |
| `POSTGRES_PASSWORD` | ComposeのPostgreSQLとJavaのDB接続で共通に使うパスワード |
| `JWT_SECRET` | JavaのJWT署名鍵。十分にランダムな32バイト以上（UTF-8）の値 |

値をファイルに保存する場合は、Gitの追跡対象外である `backend/.env` にだけ保存します。Composeはこのファイルを参照しますが、Spring Bootは自動では読み込みません。Javaを起動するプロセスの環境変数にも同じ値を設定してください。既存のローカルDBを使う場合、`POSTGRES_PASSWORD` はそのDBに設定済みのパスワードと一致させます（Composeの環境変数を変えても既存DBのパスワードは変わりません）。

既定値はありません。`POSTGRES_PASSWORD` が未設定または空ならComposeの設定解決が失敗します。Java側もDBパスワードと署名鍵の設定が必要です。`JWT_SECRET` が未設定なら起動時の設定解決に失敗し、空または32バイト未満の鍵も既存の署名鍵検証で拒否されます。
